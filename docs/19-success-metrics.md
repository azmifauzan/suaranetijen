# 19 - Success Metrics

## Product metrics

- Search success rate: query menghasilkan click entity.
- Entity page engagement.
- Repeat visitors 7/30 day.
- Rating conversion: entity viewers -> rating.
- Category/top-list CTR.
- Organic search impressions/clicks.

## Index metrics

- active entities with >=30 opinions.
- ranking-eligible entities >=100 opinions.
- opinions ingested/day.
- source diversity per entity.
- median sentiment freshness.
- duplicate suppression rate.
- unmatched mention rate.
- classifier error rate from QA sample.

## Source metrics

Per source:
- discovery yield;
- fetch success;
- candidate opinion yield;
- relevant opinion yield;
- parser failures;
- block/rate-limit events;
- cost per 1k processed opinions if paid.

## MVP validation targets

Indicative, adjust after real data:
- 100+ entities scored.
- 4+ healthy third-party adapters.
- 10k+ sentiment observations.
- search p95 <300ms server-side target.
- entity page LCP target <2.5s on reasonable mobile connection.
- measurable repeat usage or organic query growth within first validation window.
