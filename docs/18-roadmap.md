# 18 - Roadmap

## MVP

- 200 seed entities.
- public sentiment index.
- first-party rating.
- search/category/top lists.
- core adapters.

## Post-MVP 1 - Coverage & freshness

- X API if economics justify.
- more niche Indonesian forums.
- improved entity discovery from search demand.
- faster historical trend updates.
- source coverage page per entity.

## Post-MVP 2 - First-party flywheel

- optional short user reviews.
- helpful/report controls.
- entity suggestion by users.
- user follow/watch list.

## Post-MVP 3 - Data partnerships

Targets where useful:
- MediaKonsumen.
- Female Daily.
- Try & Review.
- Trustpilot Data Solutions.
- app review data.

## Post-MVP 4 - New categories

- Beauty/FMCG.
- Banks/e-wallets.
- Airlines/travel.
- SaaS/software.
- Institutions/public services where appropriate.

## Scale architecture

Only when measured:
- dedicated search engine;
- Python/GPU sentiment service;
- crawler workers on separate nodes;
- analytical database for very large history.

## Long horizon

Political/candidate sentiment is intentionally not part of MVP or near roadmap. If revisited near an election cycle, treat it as a separately reviewed product/compliance module rather than silently enabling existing generic entity functionality.
